# Sales Performance Analysis & Interactive Dashboard

## 📌 Project Overview
This project analyzes retail sales data using Python, Pandas, Excel, and Power BI to identify sales trends, regional performance, category performance, and product-level patterns.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Excel
- Power BI
- Jupyter Notebook

## 🔍 Project Workflow
Raw Data → Data Cleaning → Exploratory Data Analysis → KPI Analysis → Visualization → Power BI Dashboard → Business Insights

## 📊 Key KPIs
- Total Sales: 2.26M
- Total Orders: 4,922
- Total Customers: 793
- Total Products: 1,861
- Average Order Value: 459.48

## 📈 Analysis Performed
- Regional sales analysis
- Category-wise sales analysis
- Monthly sales trend analysis
- Top products by sales
- Sub-category sales analysis
- Interactive filtering using Power BI slicers

## 📊 Dashboard
An interactive Power BI dashboard was created to visualize sales performance and business insights.

## 📁 Project Structure
- `data/` – Dataset
- `dashboard/` – Power BI dashboard
- `screenshots/` – Dashboard screenshot
- `cleaned_sales.csv` – Cleaned dataset
- `README.md` – Project documentation
